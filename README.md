# Human Action Recognition Using 3D CNN

## 📌 Project Overview

Human Action Recognition (HAR) is a computer vision task that identifies and classifies human activities from video sequences. This project uses a 3D Convolutional Neural Network (3D CNN) to recognize actions by learning both spatial and temporal features from videos.

The model was trained and evaluated on the HMDB51 dataset and achieved an accuracy of **91.67%**, demonstrating strong performance in real-time action recognition.

## 🎯 Objectives

* Develop an automated system for recognizing human actions from videos.
* Improve action classification accuracy using Deep Learning techniques.
* Build a user-friendly interface for real-time predictions.
* Explore practical applications in surveillance, healthcare, and sports analytics.

## 📂 Dataset

The project uses the **HMDB51 Dataset**, a benchmark dataset containing 51 human action categories collected from real-world videos.

Examples of actions:

* Walking
* Running
* Jumping
* Clapping
* Smiling
* Drinking
* Sitting

## 🧠 Model Architecture

The 3D CNN model extracts both spatial and temporal information from video frames using:

* 3D Convolution Layers
* ReLU Activation Functions
* Max Pooling Layers
* Batch Normalization
* Fully Connected Layers
* Softmax Output Layer
